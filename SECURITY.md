# Segurança

Não abra issue pública para segredo exposto, token Discord, URL MongoDB com senha ou falha explorável.

1. Revogue token ou credencial exposta imediatamente.
2. Envie descrição, impacto e reprodução mínima para contato privado do mantenedor.
3. Não inclua dados pessoais desnecessários.

Arquivos locais protegidos por `.gitignore`:

```text
.env
data/
node_modules/
```
